# Wasatch Aquatic Specialties — website

The website for Wasatch Aquatic Specialties. Plain HTML/CSS/JS with no build step: every file
here is served exactly as it is, by Cloudflare Pages, at https://wasatch-acquatics-site.pages.dev/.

To preview it on your own machine, run `python3 -m http.server` in this
folder and open http://localhost:8000. To change anything, see `CLAUDE.md`:
the site is meant to be maintained by asking Claude in plain English.
